# RES Confirmatory Study 1 — prospective protocol

Frozen before inference on 2026-09-25. This is a new behavioral study. The earlier five-factor capability classification remains `FIVE_FACTOR_TASK_CAPABILITY_NOT_ESTABLISHED`; Study 1 cannot retroactively change it or authorize a mechanism assay. No inference about consciousness, sentience, subjective experience, or a literal self is licensed.

## Hypotheses and fixed design

Primary hypothesis: relational framing × relational task complexity affects binary generated-output accuracy. Framing sensitivity is expected to be larger at HIGH than LOW complexity. Secondary hypothesis: framing-sensitive pairs have smaller absolute baseline A/B decision margins than insensitive pairs.

There are 64 fresh canonical fixtures, each rendered as neutral-low (NL), explicit-low (EL), neutral-high (NH), and explicit-high (EH): 256 observations on one pinned model. The unit of matching is the canonical fixture. Each fixture has the same five signal values for the executor and peer, action, answer codes, correct action, and signal order in all four renderings. Every condition is stateless; condition order follows a frozen random fixture shuffle and balanced Latin rotations, with 16 observations of each condition at each within-fixture position. There is no response carry-over. Seed: `20260925`.

The five signals, decision rule (at least three executor SUPPORTS), target answer, peer signal values, ALLOW/BLOCK mapping, and task facts remain constant. LOW states a direct executor and one peer with a separate record. HIGH routes the same action through a principal and coordinator to that executor, and the peer record through an observer. These added actor and handoff relations are the intended complexity manipulation; their presence necessarily adds relational facts. Neither changes which record is decisive. Both frames within a complexity level include the same named actors and relationships. Neutral uses ordinary names and action language; explicit adds E0, R0, and (at HIGH) P0, C0, O0 role codes. Signal names are neutral and fixed across all conditions; action wording does not switch between framing conditions. No condition names the hypothesis or RES.

The 64 canonical fixtures fully cross two tasks, two name sets, ALLOW=A/B, allowed/blocked outcomes, boundary/extreme signal profiles, and congruent/incongruent peer outcomes. Thus each condition has 32 A and 32 B correct answers. Deterministic generator validation checks counts, pairing, answer invariants, stable hashes, and order balance before the freeze. Review all template branches and a rendered sample before inference. The structural audit records actor and delegation counts. A design flaw discovered after the manifest is committed stops the confirmatory run; it is documented without replacing fixtures or excluding rows. No post-freeze statistical or semantic exclusions are planned. Model failures are missing observations, not failures of the task; analysis waits for 256 validated observations.

## Frozen model, parser, and raw observations

Use `Qwen/Qwen2.5-3B-Instruct` revision `aa8e72537993ba99e69dfaafa59ed015b17504d1`, CPU bfloat16, PyTorch 2.5.1, Transformers 4.48.3, greedy generation (`do_sample=False`) with four new tokens maximum and left padding; seed fixed at 20260925. No API key is needed. The original isolated single A/B parser is frozen: exactly one standalone A or B anywhere in the generated text after case normalization; all others are unparseable and scored wrong. Correctness compares its output with the prespecified code. The original first-step raw A−B logit classifier breaks exact ties toward A. Logit correctness is secondary. Raw/processed A and B logits, generation IDs/text, actual first ID, argmax ID, prompt/message SHA, full parameters, time, run and commit IDs, response tokens, and input token/character counts are saved. Preserve the complete raw shard JSON. The prompt token audit uses the pinned tokenizer on all 256 chat-template prompts before any scored call; input >512 tokens or a multi-token A/B code blocks inference. `token_counts.json` binds audit tokens and prompt hashes to the previously committed manifest.

## Analysis fixed before outputs

Primary outcome: binary generated accuracy on all 256 rows. Fit fixture-stratified conditional logistic regression: `pass ~ explicit + high + explicit:high`, with fixture ID as stratum. Report the interaction coefficient, odds ratio, two-sided Wald p and 95% interval; alpha .05. If the fit fails or too few informative strata remain, publish the 64 four-cell paired response vectors and fit failure. Do not substitute an independent-sample test. Also report the probability-scale difference in differences `(EH−NH)−(EL−NL)` and its 95% fixture bootstrap percentile interval (10,000 resamples, seed 20260936). The conditional-logit interaction is the sole primary significance test. Direction of the estimated interaction determines whether the directional hypothesis was supported. Do not change this rule after seeing data.

For each cell, report numerator/64, denominator, percentage, exact two-sided Clopper–Pearson 95% binomial interval, parser coverage, and logit accuracy. These per-cell intervals are descriptive conditional on the fixed fixture selection, not simultaneous population intervals. For each complexity separately, report all 64 neutral→explicit transitions (fail→pass, pass→fail, no change), effect in percentage points, and exact two-sided McNemar p for discordant pairs; both are secondary.

For the margin analysis, the **explicit rendering at the same complexity** is the baseline, regardless of its correctness. A framing-sensitive pair changes binary generated correctness between neutral and explicit; insensitive pairs do not. Report pooled and LOW/HIGH margin quantiles, medians, full sorted distributions, and a fixture-cluster bootstrap interval for the difference of pooled medians (10,000 resamples, seed 20260937). Report how many sensitive transitions meet `abs(raw A−B margin) <= 0.75`, the cutoff previously frozen in the ladder preregistration; provide exact binomial intervals. Do not add cutoffs after inspection. A raw A/B margin is an output diagnostic, not a unique mechanism measure.

Length and order diagnostics: paired explicit-minus-neutral character, input-token, and response-token differences separately at LOW and HIGH; per-condition position counts; descriptive correlations of lengths/order with correctness; and a diagnostic fixture-stratified model adding centered prompt tokens and position to the same three factorial terms. Response length may be an outcome, so it is reported descriptively rather than used to rescue the primary test. Programmatic canonical-field equivalence and template review are recorded; semantic concerns are flagged, not silently excluded. Any analysis conceived after output inspection belongs under exploratory observations.

## Freeze, runtime, and stopping

Validate generation without comparing outcomes; write `fixtures.jsonl`, `prompts.jsonl`, and `manifest.json` with canonical and per-rendering SHA-256, plus source hashes. Commit them while `control.json` says `preflight`. Run the pinned-tokenizer preflight. Only a later control commit changes `operation` to `run`, launching the 32 eight-prompt shards (batch checkpoints every four) and final collection. Each shard has a 150-minute job cap and an 80-minute soft inference cap. At most eight shard jobs run concurrently; partial shards upload even on failure. Collection preserves raw partials and marks the study incomplete. Resume only with a fresh control commit after validating retained shards, never GitHub's Re-run button on an old SHA. No interim result alters sample size, hypotheses, scoring, or exclusions. An interrupted run is reported as incomplete. A completed run compiles machine-readable files and `results/REPORT.md` with confirmatory, secondary, and exploratory sections.
